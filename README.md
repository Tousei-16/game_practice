# C++ ターン制バトルゲーム

C++で一から設計・実装した、コンソール上で動作するターン制バトルゲームです。プレイヤーは攻撃・防御・回復を選択し、敵との連続戦闘を通してダンジョンのクリアを目指します。

## 制作目的

C++のクラス設計や継承への理解を深め、複数の機能を組み合わせてゲームとして動作させることを目的に制作しました。

## 主な機能

- 攻撃・防御・回復の選択
- 素早さによる行動順の決定
- 敵のHPと確率に基づく行動選択
- 経験値の獲得とレベルアップ
- 4段階の難易度選択
- 複数の敵との連続戦闘
- 不正な入力に対する再入力処理

## 設計・実装の工夫

### クラスによる共通処理の整理

プレイヤーと敵に共通するステータスや処理を、基底クラスの`Character`にまとめました。`Player`と`Enemy`はこのクラスを継承し、それぞれの攻撃・回復・情報表示を実装しています。

### 状態に応じた敵の行動選択

敵のHPが半分以上の場合は攻撃し、半分未満の場合は75%の確率で攻撃、25%の確率で回復する仕組みにしました。また、プレイヤーが防御を選択した場合は、防御力に応じて被ダメージを減らします。

### 戦闘処理と入力処理の分離

行動選択の入力処理と、プレイヤーの行動処理をそれぞれ関数にまとめました。文字や範囲外の数値が入力された場合は、再入力を求めます。

## 使用技術

- C++
- C++標準ライブラリ
- 外部ライブラリ不要



## 操作方法

表示される選択肢の番号を入力し、Enterキーで決定します。

### 難易度選択

| 入力 | 難易度 | 敵の数 | 敵のレベル |
|---|---|---|---|
| 1 | Easy | 2体 | 1〜5 |
| 2 | Normal | 4体 | 6〜10 |
| 3 | Hard | 6体 | 11〜15 |
| 4 | Boss | 1体 | 20 |

### 戦闘中

| 入力 | 行動 | 内容 |
|---|---|---|
| 1 | 攻撃 | 敵に攻撃力分のダメージを与える |
| 2 | 防御 | そのターンの被ダメージを防御力分減らす |
| 3 | 回復 | 最大HPの半分を回復する。最大HPは超えない |

ダンジョンクリア後は、`1`で続行、`2`で終了します。続行時はプレイヤーの状態を引き継ぎます。
